# AIBE4_FinalProject_Team2_FE

## 1. 의존성(라이브러리) 설치
```
npm i
```

## 2. 로컬 실행
```
npm run dev
```

## 파일 구조

```text
src/
├── api/              # Axios 인스턴스 및 API 호출 함수 관리
├── assets/           # 이미지, 아이콘, 파비콘 등 정적 리소스
├── components/       # 재사용 가능한 공통 컴포넌트
│   ├── domain1/      
│   ├── domain2/      
│   ├── domain3/      
│   └── global/       
└── pages/            # 라우트별 페이지 컴포넌트
    ├── domain1/      
    ├── domain2/      
    └── domain3/
```
